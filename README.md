# Made From Fog — Public Surface v0.6

Static-first site for https://made-from-fog.co.uk.

The v0.6 refresh adds or updates three evidence-based workshop stories:

- Arcane Hub Reliquary — lighting experiments, the move to HueForge and the real nine-tile installation;
- Old laptop, new job — the reused Linux Hub, including the Pi-hole experiment and its home behind the Reliquary;
- Unnecessary Triumphs — the delayed fishing-award production and Memento Sciure artwork.

Image provenance is explicit. The Reliquary image is a user-supplied installation photograph. Memento Sciure is labelled as design artwork, not a finished-object photograph. Earlier generated Reliquary studies are not presented as unenhanced photography.

Private infrastructure details, credentials, household records, personal trip photographs and identifiable private likenesses remain outside the public site.

The Visitors' Notebook continues to send notes privately through its existing external form endpoint. Notes are never displayed automatically; publication always requires human review.
