# Made from Fog — Holding Page

Minimal public holding page for `made-from-fog.co.uk`.

The front page intentionally remains simple: one landscape-first current image and no wider site infrastructure.

## Visual Ledger v0.1

A bounded archive proof lives at `archive.html`. It preserves a few earlier visual states without changing the front page into a conventional website.

To update deliberately:

1. move/retain the outgoing current image as an archive asset if it should be kept;
2. add one archive entry to `archive.html` with image, date and short title;
3. replace `holding-image.png` with the new current image;
4. commit the change.

Do not expand this repository into a larger site until another concrete public-facing need is adopted.
