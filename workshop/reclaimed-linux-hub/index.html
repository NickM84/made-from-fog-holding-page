WORKSHOP / REUSED HARDWARE

Old laptop, new job

An older laptop, a reused drive and a Linux installation turned into a useful little machine for the house and workshop.

One more job for an old laptop

I had an older Lenovo laptop and a drive that could be reused, so I tried giving the hardware a different job rather than replacing it with a new server. The machine now runs Linux Mint and provides a local place for small household and workshop applications.

It started as a practical experiment. I wanted somewhere that could stay on, hold a little state and run things without relying on whichever computer I happened to be using.

What it has been used for

The machine became the base for my PanOptiHome Hub work: a household console, inbox and calendar experiments, studio intake and other small tools. It has also been a useful place to learn about Linux services, recovery and what deserves to be kept between experiments.

The hardware is an ordinary recycled Lenovo G50-45 running Linux Mint 22.3. None of this requires an expensive server to start learning.

Still changing

It's a working machine, not a polished appliance. Some services are experiments; others have become part of the household setup. The next interesting part is deciding which jobs belong on it permanently and which should remain easy to remove.
